# Presetهای Parser

فایل‌های JSON داخل `resources/parsers/` قابل Version control و انتقال هستند. نسخه اولیه با الگوی «واریز بانک سامان» نصب می‌شود و این قالب را می‌خواند:

```text
بانك سامان
واريز مبلغ  1,000,000ريال
به 9001-800-2156834-1
مانده 1,397,604
1405/5/13
1:57
```

خروجی این نمونه `1,000,000` ریال و نوع تراکنش `credit` است؛ عدد «مانده» مبلغ واریز محسوب نمی‌شود. تبدیل نویسه‌های عربی/فارسی مثل `بانك/بانک` و `واريز/واریز` نیز پیش از تطبیق انجام می‌شود.

به‌دلیل تغییر احتمالی قالب پیامک بانک‌ها، الگو را با یک پیامک واقعی همان حساب در صفحه ویرایش کارت آزمایش کنید. فیلدهای فایل با مدل `sms_parsers` هم‌نام‌اند و keywordها آرایه JSON هستند.
