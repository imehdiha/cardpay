# نصب

1. یک دیتابیس خالی و کاربری با مجوز ساخت/تغییر جدول بسازید.
2. ZIP Release را استخراج کنید. برای سایت واقعی، بهترین حالت ساخت یک زیردامنه مانند `pay.example.com` و تنظیم Document Root آن روی پوشه `public/` این پروژه است؛ Root و Subdirectory نیز با `.htaccess` پشتیبانی می‌شوند.
3. پوشه‌های `storage`, `storage/logs`, `storage/cache`, `storage/sessions`, `storage/uploads`, `public/uploads` را برای PHP قابل نوشتن کنید.
4. URL را باز کنید. برنامه تا قبل از نصب به `/install` هدایت می‌شود.
5. بررسی سرور، دیتابیس، مدیر و تنظیمات عمومی را تکمیل کنید.
6. Installer جدول‌ها، `.env`، APP_KEY، مدیر، اتصال داخلی فروشگاه و `storage/installed.lock` را می‌سازد.
7. Public Key و Secret اتصال را از صفحه موفقیت نصب ذخیره کنید.
8. وارد پنل شوید و مسیر «راه‌اندازی» را دنبال کنید: سایت، کارت مقصد، الگوی پیامک و موبایل.

برای سایت اختصاصی PHP، پس از نصب از صفحه «اتصال سایت» استفاده کنید و راهنمای `custom-php-integration.md` را ببینید.

Installer پس از نصب عمداً HTTP 409 و صفحه قفل نمایش می‌دهد. نصب مجدد فقط با حذف دستی lock و بررسی داده‌های قبلی ممکن است.
