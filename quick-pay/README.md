# لندینگ پرداخت سریع

این پوشه یک صفحه پرداخت مستقل PHP برای اتصال به CardPay است. مبلغ محصول ۱۰٬۰۰۰ تومان است و از پرداخت‌کننده نام، موبایل یا اطلاعات دیگری دریافت نمی‌کند.

## راه‌اندازی روی هاست

1. پوشه `quick-pay` را داخل مسیر دلخواه سایت آپلود کنید.
2. فایل `config.php` را باز کنید و این سه مقدار را از بخش «اتصال سایت» پنل CardPay وارد کنید:
   - `cardpay_url`: آدرس نصب CardPay
   - `public_key`: کلید عمومی اتصال سایت
   - `secret`: کلید محرمانه اتصال سایت
3. دامنهٔ سایت دفتر را در `Allowed domains` همان اتصال CardPay مجاز کنید.
4. اگر آدرس پوشه پشت CDN یا Proxy درست تشخیص داده نمی‌شود، `public_url` را با آدرس کامل پوشه پر کنید؛ مثلاً `https://office.example.com/pay`.

فایل `.htaccess` دسترسی مستقیم وب به `config.php` را می‌بندد. روی Nginx نیز باید دسترسی مستقیم به این فایل را در تنظیمات سرور مسدود کنید. مقادیر اتصال را بین کوتیشن‌های روبه‌روی گزینه‌های مربوط قرار دهید؛ داخل نام گزینه یا تابع دیگری ننویسید.

## تغییر متن و مبلغ

نام دفتر، نام محصول، توضیح و مبلغ در ابتدای `config.php` قرار دارند. مبلغ این فایل بر حسب تومان است و برای API به‌صورت خودکار به ریال تبدیل می‌شود.

## نیازمندی‌ها

- PHP 8.1 یا جدیدتر
- افزونه‌های cURL، JSON، Session و OpenSSL
- HTTPS برای استفادهٔ عمومی

صفحهٔ نتیجه وضعیت را مستقیماً از Verify API می‌گیرد. برای حفظ حریم خصوصی هیچ سفارش یا اطلاعات شخصی در دیتابیس این پوشه ذخیره نمی‌شود؛ شناسهٔ پرداخت فقط تا دو ساعت در Session همان مرورگر باقی می‌ماند.

گزینه `show_gateway_errors` در زمان راه‌اندازی خطای CardPay را روی صفحه نشان می‌دهد. پس از تکمیل تست می‌توانید مقدار آن را `false` کنید.

کلاینت برای سازگاری با DNS هاست‌های اشتراکی از IPv4 استفاده می‌کند و تا ۱۸ ثانیه برای برقراری اتصال منتظر می‌ماند.
